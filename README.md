# 📺 YouTube 조회수 기반 추천 영상 필터링 스크립트

## 🔧 개요

Tampermonkey 확장 프로그램에서 동작하는 사용자 스크립트입니다.

- 내가 **구독하지 않은 채널**의
- **조회수가 일정 기준보다 낮은 영상**은
- 추천 목록이나 검색 결과에서 **자동으로 제거**됩니다.
- **생방송 시청자 수**도 조회수처럼 인식됩니다.
- **구독/구독 해제 버튼을 누르면 자동으로 구독 목록에 반영**됩니다.

---

## 📦 설치 방법

1. [Tampermonkey 확장 프로그램](https://www.tampermonkey.net/) 설치
2. 아래 링크 클릭으로 스크립트 설치

👉 [**스크립트 설치하기**](https://github.com/YOUR_USERNAME/YOUR_REPO/raw/main/youtube-lowview-filter.user.js)

## 🛠 Tampermonkey 메뉴 기능

| 메뉴 이름 | 설명 |
|-----------|------|
| 📤 구독 목록 추출하러 이동 | 구독 채널 페이지로 이동 |
| 📥 현재 페이지에서 구독 목록 추출 | 현재 보이는 채널들을 구독 목록으로 저장 |
| 📊 조회수 기준 설정 | 기준 조회수 설정 (예: 1000 → 1천회 미만 영상 제거) |
| 🧨 구독 목록 초기화 | 저장된 구독 목록 전체 삭제 |

## 💡 참고 사항

- `1.2천회`, `5.4만회`, `2.3억회`, `"1,234명 시청중"` 등 다양한 단위 모두 지원
- 구독 버튼 클릭 시 자동 동기화 (삭제도 포함)
- 필터링된 영상은 빈칸 없이 자연스럽게 제거됨
- 저장된 목록은 Tampermonkey 내에 안전하게 유지되며 외부 서버와 통신하지 않음
